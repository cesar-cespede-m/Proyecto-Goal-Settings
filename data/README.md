# Datos de desarrollo y demostración

Usar únicamente datos sintéticos, sandbox o debidamente anonimizados y autorizados. No incorporar información de producción, datos personales, archivos internos de Babel ni secretos.

Los ejemplos de [`synthetic/`](synthetic/README.md) son generados para probar el flujo de análisis y ML. No representan resultados de Goal Settings ni indicadores de la empresa.

Antes de usar un dataset externo, revisar licencia, procedencia, anonimización, definición de variables y permiso para compartirlo. Los CSV descargados deben guardarse en `data/samples/`, fuera de commits, hasta completar esa revisión.
